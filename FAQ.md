# MY-ZSH CHEAT SHEET & FAQ

## 📁 Навигация и файловые операции
- **`mkcd <папка>`** / **`take <папка>`** — Создать папку (включая промежуточные родительские директории) и сразу перейти в нее.
- **`gclone <url> [целевая_папка]`** / **`gclcd <url>`** — Клонировать Git-репозиторий и автоматически перейти в созданную папку репозитория.

## 📦 Работа с архивами
- **`x <архив>`** / **`extract <архив>`** — Автоматическая распаковка архивов на основе расширения (`.tar.gz`, `.zip`, `.rar`, `.7z`, `.tar.bz2`, `.gz` и др.).
- **`untargz <архив>`** — Быстрая распаковка `.tar.gz` файлов (`tar -xvzf`).

## ⚡ Сокращения пакетного менеджера (`a`)
- **`a i <пакет>`** — Установить пакет (`apt install` / `pkg install`).
- **`a u`** — Обновить список пакетов (`apt update`).
- **`a up`** — Обновить все установленные пакеты (`apt upgrade -y`).
- **`a all`** — Выполнить `update` + `upgrade` одной командой.

## 🚀 Управление конфигурацией my-zsh
- **`zsh-faq`** / **`myzsh-faq`** — Вывести краткую справку по основным алиасам прямо в терминале.
- **`my_zsh_update_check 1`** — Принудительно проверить и притянуть обновления с GitHub (игнорируя 6-часовой таймер).
- **`my_zsh_do_update_check`** — Прямая загрузка обновленных `zshrc.managed` и `~/.zshrc`.

## 🛠 Персональная кастомизация
- Все личные настройки, ключи, пути и дополнительные алиасы пишите в файл **`~/.zshrc.local`** или в файлы в каталоге **`~/.zshrc.d/*.zsh`**.
- Эти файлы никогда не перезаписываются при автоматических обновлениях `my-zsh`.
