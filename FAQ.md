# MY-ZSH CHEAT SHEET & FAQ

## 📁 Навигация и файловые операции
- **`mkcd <папка>`** / **`take <папка>`** — Создать папку (включая промежуточные родительские директории) и сразу перейти в нее.
- **`gclone <author/repo или url> [целевая_папка]`** / **`gclcd <url>`** — Клонировать Git-репозиторий и автоматически перейти в созданную папку репозитория.

## 📦 Работа с архивами
- **`x <архив>`** / **`extract <архив>`** — Автоматическая распаковка архивов на основе расширения (`.tar.gz`, `.zip`, `.rar`, `.7z`, `.tar.bz2`, `.gz` и др.).
- **`untargz <архив>`** — Быстрая распаковка `.tar.gz` файлов (`tar -xvzf`).

## ⚡ Сокращения пакетного менеджера (`a`)
- **`a i <пакет>`** — Установить пакет (`apt install` / `pkg install`).
- **`a u`** — Обновить список пакетов (`apt update`).
- **`a up`** — Обновить все установленные пакеты (`apt upgrade -y`).
- **`a all`** — Выполнить `update` + `upgrade` одной командой.

## 🚀 Управление конфигурацией my-zsh
- **`npm s`** — `npm start` при установленном NVM, включая первый вызов после ленивой загрузки Node.js.
- **`zsh-faq`** / **`myzsh-faq`** — Вывести краткую справку по основным алиасам прямо в терминале.
- **`my_zsh_update_check 1`** — Принудительно проверить и притянуть обновления с GitHub (игнорируя 6-часовой таймер).
- **`my_zsh_do_update_check`** — Проверка и обновление `zshrc.managed` и `loader.managed.zsh` с блокировкой; входной `~/.zshrc` сохраняется.

## 🛠 Персональная кастомизация
- Все личные настройки, ключи, пути и дополнительные алиасы пишите в файл **`~/.zshrc.local`** или в файлы в каталоге **`~/.zshrc.d/*.zsh`**.
- Эти файлы никогда не перезаписываются при автоматических обновлениях `my-zsh`.

## Терминал и шорткаты awk

- **`logs`** — перейти в `/var/log`.
- **`msf [аргументы]`** — запустить `msfconsole -q` без стартового баннера; аргументы передаются дальше.
- **Alt+A** (или **Esc**, затем **a**) — показать меню awk с примерами и выбрать шаблон:

| Клавиша | Шаблон | Куда ставится курсор |
| --- | --- | --- |
| 1 | `awk '{print $1}'` | После номера поля `1` |
| 2 | `awk -F ':' '{print $1}'` | После разделителя `:` |
| 3 | `awk '$1 == "" {print $0}'` | Между двойными кавычками для значения |
| 4 | `awk '{sum += $1} END {print sum}'` | После номера суммируемого поля `1` |

Любая другая клавиша отменяет выбор. `$0` означает всю строку, `$1`, `$2` и т. д. — отдельные поля.
Например: набрать `ps aux | `, нажать Alt+A, затем 1.
Стрелки перемещают курсор; **Ctrl+E** / **End** переводят в конец команды, где можно дописать имя файла.
Повторный Alt+A вставляет ещё один шаблон. Чтобы заменить предыдущий, сначала удалить его.

## Конфиг msfconsole

`msf` — алиас оболочки. Следующие сокращения работают **внутри msfconsole**:

- **`s <запрос>`** — `search <запрос>`.
- **`so`** — `show options`.
- **`alias`** — посмотреть список сокращений.

Они определены в `msfconsole.rc`: `load alias` загружает встроенный плагин.
Metasploit автоматически читает `~/.msf4/msfconsole.rc` при запуске без явного `-r`.
Установщик `install.sh` предлагает установить этот файл отдельно; для установки без вопроса задать `MY_ZSH_INSTALL_MSFCONSOLE=1`.
В `termux_zsh.sh` установки этого конфига нет. Для ручной установки см. раздел MSFCONSOLE в README; существующий файл сначала сохранить или объединить настройки вручную.

После изменения `~/.zshrc.local` выполнить `source ~/.zshrc.local`; после обновления основной конфигурации открыть новый терминал.
